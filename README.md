# Youth Advocates Network (YAN) Management & Collaboration Platform

## 📌 Project Overview

The Youth Advocates Network (YAN) Management & Collaboration Platform is a full-stack web application designed to serve as a centralized digital ecosystem for youth-led organizations.

The platform aims to automate organizational workflows, strengthen collaboration, and provide data-driven insights to support YAN’s mission of empowering youth initiatives.

This project is being developed as part of a Software Engineering implementation focused on scalable architecture, role-based access, and real-world system design.

---

## 🎯 Objectives

- Centralize membership applications and vetting processes
- Enable performance tracking and reporting for member organizations
- Provide a capacity-building resource hub
- Support collaboration through events, opportunities, and shared tools
- Deliver real-time dashboards for administrative decision-making

---

## 🧠 Core Features

### 1. Authentication & User Roles

- Secure user registration and login
- JWT-based authentication
- Role-based access control:
  - Admin
  - Member
  - Applicant
  - Partner
  - Public users

---

### 2. Organizational Vetting System

- Multi-step membership application submission
- Admin review dashboard
- Application status tracking:
  - submitted
  - screening
  - under_review
  - approved
  - rejected
- Automated notifications

---

### 3. Performance Tracking Dashboard

- Member organizations submit activity reports
- KPI tracking aligned with YAN strategic goals
- Aggregated analytics dashboard for admins
- Exportable reports

---

### 4. Capacity Building & Collaboration Hub

- Digital resource repository
- Searchable training materials
- Skill development modules
- Opportunity board (funding, partnerships, courses)
- Event calendar

---

### 5. Automated Communication System

- Weekly newsletter generation
- Event and opportunity notifications
- Resource updates
